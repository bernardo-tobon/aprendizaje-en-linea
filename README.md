# aprendizaje-en-linea
Implementación y compararación de algoritmos de aprendizaje en línea sobre la demanda diaria de bicicletas (Bike Sharing Dataset). Se construyen 5 expertos basados en reglas simples de pronóstico, se combinan mediante Hedge, y se comparan contra Follow the Leader (FTL) y Online Gradient Descent (OGD).
